# Jawaban Pertanyaan Pratikum 1 HTML Dasar
## 1. Apa fungsi deklarasi <!DOCTYPE html> pada dokumen HTML?
Jawaban:
Fungsi <!DOCTYPE html> ini bukan tag HTML, melainkan deklarasi untuk memberi browser bahwa dokumen tersebut menggunakan standar HTML5. Tanpa ini, browser mungkin akan masuk ke "quirks mode" yang bisa bikin tampilan web jadi berantakan.
## 2. Apa perbedaan antara tag, elemen, dan atribut pada HTML? 
Jawaban:
- Tag: Penanda awal dan akhir (contoh: <p> dan </p>)
- Elemen: Keseluruhan blok dari tag pembuka sampai tag penutup, termasuk isinya.
- Atribut: Informasi tambahan di dalam tag pembuka (contoh: class="teks").
## 3. Apa perbedaan <p> dengan <br>? Jelaskan penggunaannya.
Jawaban:
- <p> (Paragraph): Digunakan untuk membuat paragraf baru. Secara otomatis memberi jarak (margin) di atas dan bawah teks.
- <br> (Break): Digunakan untuk pindah ke baris baru saja tanpa membuat paragraf baru atau menambah jarak antar baris yang besar.
## 4. Apa fungsi atribut href pada tag <a>? 
Jawaban:
Atribut href pada tag <a> href singkatan dari hypertext reference. Fungsinya untuk menentukan alamat tujuan (URL) saat link tersebut diklik.
## 5. Apa perbedaan hyperlink ke halaman internal dengan hyperlink ke website eksternal? 
Jawaban:
- Internal: Mengarah ke halaman lain di dalam website yang sama (contoh: href="about.html).
- Eksternal: Mengarah ke website milik orang lain (contoh: href="https://google.com")
## 6. Apa fungsi atribut src dan alt pada tag <img>? 
Jawaban:
- src (Source): Menentukan lokasi file gambar.
- alt (Aternative Text): Memberikan deskripsi teks jika gambar gagal dimuat atau untuk membantu pembaca layar (screen reader) bagi tunanetra.
## 7. Apa perbedaan penggunaan <ul> dan <ol>?
Jawaban:
- <ul> (Unordered List): Daftar tanpa urutan angka, biasanya pakai simnbol (bullets).
- <ol> (Ordered List): Daftar dengan urutan angka atau huruf (1, 2, 3 atau a, b, c).
## 8. Apa yang terjadi jika path gambar pada atribut src salah? 
Jawaban:
Path gambar salah pada src gambar tidak akan muncul. Browser akan menampilkan ikon "gambar rusak" (broken image) dan akan menampilkan teks dari atribut alt.
## 9. Mengapa struktur heading h1 sampai h6 perlu digunakan secara terstruktur? 
Jawaban:
Heading h1 sampai h6 digunakan untuk mengatur tingkatan judul dan subjudul pada halaman HTML. Penggunaan yang terstruktur membuat isi halaman lebih mudah dibaca dan membantu menunjukkan hubungan antara judul utama dan bagian-bagian di bawahnya.
## 10. Apa fungsi komentar <!--...--> dalam kode HTML?
Jawaban:
Komentar digunakan untuk memberikan catatan atau keterangan di dalam kode HTML. Komentar tidak ditampilkan pada halaman web sehingga dapat membantu programmer memahami kode tanpa memengaruhi tampilan halaman.
